# Company Portal Management System

A web-based Company Portal Management System developed using PHP, MySQL, Bootstrap 5, HTML, CSS, and JavaScript. The application provides separate portals for Admins and Employees, allowing efficient employee management, authentication, and work tracking.

## Features

### Admin Portal

* Secure Admin Login
* Dashboard with Employee Statistics
* Create Employee Accounts
* Generate Employee IDs
* Assign Individual Login Credentials
* View Employee Details
* Edit Employee Information
* Delete Employee Records
* Search Employees
* Manage Employee Database

### Employee Portal

* Secure Employee Login
* Personal Dashboard
* View Profile Information
* Access Employee Details
* Department and Designation Information
* Individual Account Access

### Database Management

* MySQL Database Integration
* Employee Records Storage
* Admin Records Storage
* Password Hashing for Security
* Session-Based Authentication
